## ✨ 주요 기능

<br/>

### 📔 식사일지 작성
> 오늘 먹은 음식을 기록하고 나만의 식사 히스토리를 만들어보세요.

### 🎡 오늘 뭐먹지? 룰렛
> 메뉴 고민은 이제 그만! 룰렛이 오늘의 메뉴를 대신 골라드립니다.

### 🧬 나만의 식성 지표 **FOODTI**
> 내가 즐겨 먹는 음식을 분석해 나만의 식성 유형을 지표로 확인하세요.

### 🗺️ 위치 기반 식사일지 조회
> 지도를 통해 내가 어디서 무엇을 먹었는지 한눈에 확인할 수 있어요.

<br/>

## 🚀 로컬 실행 방법

```bash
# 패키지 설치
pnpm install

# 개발 서버 실행
pnpm dev
```

> ⚠️ **Node.js** 및 **pnpm** 이 설치되어 있어야 합니다.
